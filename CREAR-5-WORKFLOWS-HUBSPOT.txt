¿QUÉ ES UN WORKFLOW?

Es una automatización que:
1. Espera un EVENTO (ej: "Agregaste un restaurante")
2. Espera UN TIEMPO (ej: "5 días")
3. Realiza UNA ACCIÓN (ej: "Envía email")
4. Actualiza UN DATO (ej: "Email_Sequence_Stage = Email 2 enviado")

PASO 1.1: Ir a WORKFLOWS
═══════════════════════════════════════════════════════════════════════════════════════

En HubSpot:
- Menú izquierdo → "Automation"
- Click en "Workflows"

Se abre la página de Workflows.

Ves un botón azul que dice: "Create workflow"

PASO 1.2: Click en "Create workflow"
═══════════════════════════════════════════════════════════════════════════════════════

Una ventana se abre con opciones.

Verás:
┌────────────────────────────────┐
│ Start from blank               │
│ Start from a template          │
│ Start from a saved workflow    │
└────────────────────────────────┘

Click: "Start from blank"

PASO 1.3: Selecciona el OBJETO
═══════════════════════════════════════════════════════════════════════════════════════

Te pregunta: "Which object is this workflow for?"

Opciones:
- Contact ← ESTO
- Deal
- Ticket

Click: "Contact"

PASO 1.4: Dale un NOMBRE al workflow
═══════════════════════════════════════════════════════════════════════════════════════

Te pregunta: "What do you want to name this workflow?"

Llena con:
Restaurant_Sequence_1_Initial_Contact

Click: "Create"

Se abre el EDITOR de workflows.

PASO 1.5: AGREGAR TRIGGER (Cuándo se dispara)
═══════════════════════════════════════════════════════════════════════════════════════

Ves una pantalla con:
┌─────────────────────────────────────────────┐
│ + Add trigger                               │
│                                             │
│ (Un espacio vacío para agregar el trigger) │
└─────────────────────────────────────────────┘

Click: "+ Add trigger"

Se abre un menú. Busca y selecciona:

"Contact property value changes"

Luego aparecen campos para llenar:

Property: "Restaurant_Score"
Operator: "is greater than or equal to"
Value: "80"

[Esto significa: se dispara cuando agregas un contacto con score ≥80]

Click: "Set trigger"

PASO 1.6: AGREGAR ACCIÓN 1 - DELAY (Esperar 1 día)
═══════════════════════════════════════════════════════════════════════════════════════

Ves otro botón:
Click: "+ Add action"

Se abre un menú. Busca:

"Delay"

Aparecen campos:

Type: "Delay for a specific amount of time"
Value: "1"
Unit: "day"

Click: "Save action"

PASO 1.7: AGREGAR ACCIÓN 2 - SEND EMAIL
═══════════════════════════════════════════════════════════════════════════════════════

Click: "+ Add action"

Busca: "Send email"

Aparece un campo:

Select template: Busca y selecciona "Email_1_Initial_Contact_Restaurant"

[Si no la ves, significa que aún no creaste los emails. Regresa y créalos primero.]

Click: "Save action"

PASO 1.8: AGREGAR ACCIÓN 3 - UPDATE PROPERTY
═══════════════════════════════════════════════════════════════════════════════════════

Click: "+ Add action"

Busca: "Update contact property"

Aparecen campos:

Property: "Email_Sequence_Stage"
Set value to: "Email 1 enviado"

[Esto marca que el email 1 fue enviado, para que el siguiente workflow sepa cuándo dispararse]

Click: "Save action"

PASO 1.9: ACTIVAR EL WORKFLOW
═══════════════════════════════════════════════════════════════════════════════════════

Arriba a la DERECHA, ves un toggle:

OFF (rojo/gris)

Click en él para cambiar a:

ON (verde)

Una ventana te pregunta:
"Are you sure you want to enable this workflow?"

Click: "Enable"

El workflow está ACTIVO ✓

RESULTADO WORKFLOW 1:
→ Trigger: Contact score ≥80
→ Delay: 1 día
→ Acción: Envía Email 1
→ Actualiza: Email_Sequence_Stage = "Email 1 enviado"

========================================================================================
TROUBLESHOOTING
========================================================================================

PROBLEMA: "No encuentro el email template que necesito"
SOLUCIÓN: Ve a Marketing → Email
Verifica que existan los 5 emails:
- Email_1_Initial_Contact_Restaurant
- Email_2_Followup_Day5
- Email_3_ProposalValue_Day10
- Email_4_Reactivation_Day15
- Email_5_ExecutiveProposal_Day20

Si faltan, créalos primero antes de hacer los workflows.

PROBLEMA: "El toggle de activación no funciona"
SOLUCIÓN: Probablemente hay un error en el workflow.
Revisa que:
- El trigger está correctamente configurado
- Cada acción está "Saved"
- No hay campos vacíos

PROBLEMA: "¿Cómo edito un workflow después de activarlo?"
SOLUCIÓN: Ve a Workflows → Click en el nombre → Edit
Haz cambios → Save changes
(Los cambios afectan futuros emails, no los ya enviados)

PROBLEMA: "¿Puedo pausar un workflow?"
RESPUESTA: Sí. Ve a Workflows → Toggle ON → OFF
Se pausa. Luego lo vuelves a activar.

PROBLEMA: "¿Qué pasa si alguien responde antes de la secuencia?"
SOLUCIÓN: Idealmente creas un workflow que detecte replies y pause la secuencia.
Por ahora, puedes pausal el workflow manualmente.

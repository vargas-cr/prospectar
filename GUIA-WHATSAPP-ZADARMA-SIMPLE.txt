========================================================================================
TROUBLESHOOTING
========================================================================================

❌ "python: command not found"
→ Python no está en PATH
→ Instala de nuevo y marca "Add Python to PATH"

❌ "ModuleNotFoundError: requests"
→ No instalaste las librerías
→ Vuelve a ejecutar: pip install requests

❌ "No encuentra leads.csv"
→ Olvidaste descargar el CSV del Sheet
→ O está en otra carpeta

❌ "Error de Zadarma"
→ API Key o Secret incorrectos
→ O no tienes crédito en Zadarma

❌ "El teléfono no es válido"
→ Asegúrate que esté en formato: +54 9 351 123-4567
→ Sin espacios: +54 9351123456
